# Original assets · Operation Gryning

`karlstad-materials.webp` is an AI-generated albedo atlas commissioned for this game, generated with the OpenAI image generation tool on 2026-09-27. The generated image was converted to WebP without changing its content. `district.js` reads the four quadrants. Approximate bump textures are derived at runtime; this is not a measured scan set. Other geometry, gallery studies and the vector app icon are original procedural/code artwork.

Generation prompt:

> Use case: photorealistic-natural. Asset type: production game PBR albedo texture atlas, square 2048x2048. Create a perfectly orthographic flat texture atlas divided into EXACTLY FOUR EQUAL QUADRANTS with NO borders, NO labels, NO text, NO objects, NO perspective. Each quadrant is a continuous material texture suitable for UV-mapped 3D buildings in a realistic Swedish city FPS. TOP LEFT: warm ochre lime plaster, very fine weathered grain, subtle chipped edges and hairline cracking, historical Karlstad architecture. TOP RIGHT: red-orange clay brick wall in horizontal stretcher bond, realistic small mortar lines, modest weathering, uniform scale. BOTTOM LEFT: Swedish pale grey granite rectangular paving slabs, tightly laid, fine mineral detail and hairline joins, only subtle stains, no plants. BOTTOM RIGHT: aged dark grey-green standing seam sheet metal roof with regular parallel vertical seam ridges, subtle zinc patina and fine scratches. Photorealistic scan quality albedo, flat even overcast diffuse lighting, absolutely no directional shadows, no highlights, no vignette, no buildings or windows. Full-bleed each quadrant, crisp detailed surfaces. Neutral natural colors, no cinematic grading. This is a material asset sheet, not an illustration or scene.

The delivered atlas is 1254 × 1254 pixels; runtime quadrants use 512 × 512. The prompt's requested dimensions are not a claim about the delivered file. Source references for the city's architectural interpretations remain in `../SOURCES.md`.
