# TestSpel

Karlstad utvecklas nu **mobile first som installerat iOS/Android-spel**.

- [Native Unity-projekt](native-unity/README.md) — mobil FPS, åtta besökbara spelinteriörer, zombieöverlevnad, lag-XP och lokalt Wi-Fi-samspel i källkod. **Unitybygge och fysisk telefonverifiering återstår; ingen installerbar app är publicerad ännu.**
- [Befintlig Karlstad-webbpilot](https://tryggspel.github.io/TestSpel/karlstad-city/) — stadsäventyr, Soljakten och Zombie Apocalypse. Den kör fortfarande Babylon.js; Unity-projektet ligger separat.
- [Tora Bora FPS](tora-bora/fps/index.html) — tidigare spelprojekt.

För att börja nativearbetet: öppna `native-unity` i Unity 6000.3.25f1 och följ dess README. Genereringsmenyn bygger scenen och tillgångarna från originalkällkod. Läs särskilt [verifieringsplanen](native-unity/Docs/TESTPLAN.md) och [platsunderlagen](native-unity/Docs/PLATSUNDERLAG.md).
